How to Use Branding Auditor

Welcome to the Branding Auditor user guide. Follow the instructions below to run repository scans, manage authentication, and trigger REST API audits.

1. Authenticating & Accessing the System

  1. Navigate to the login page at /login.
  2. Enter your registered credentials (managed via User entity and UserRepository).
  3. Upon successful authentication, Spring Security will redirect you to the main dashboard (/dashboard).

2. Running a Workspace Repository Scan

  1. Click "Run New Audit" on the Dashboard or navigate directly to /audit.
  2. In the Directory Target Path input box, type or paste the absolute system path to your project folder (e.g., C:\projects\my-repo or /home/user/projects/my-repo).
  3. Click "Start Scan".
  4. The RepositoryScanner will traverse the directory tree, and BrandingAnalyzer will evaluate code files for TODO, FIXME, and branding policy compliance.

3. Reviewing Audit Findings & Outputs

  • Dashboard Overview: High-level execution status is displayed directly on the Dashboard view.
  • Report File: The system automatically invokes ReportGenerator to compile findings (BrandingObservation records) into a structured repository-report.txt file saved to the project root.

4. Programmatic Scans via REST API

For automated CI/CD pipelines or headless invocations, send a POST request to the REST controller:

  • Endpoint: POST /api/audit/run
  • Header: Content-Type: application/json
  • Payload: {"targetPath": "/path/to/repo", "status": "PENDING"}
  • Response: Returns the updated AuditDto object with completed status telemetry.
